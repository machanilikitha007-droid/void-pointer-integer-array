# Void Pointer with Integer Array

## Author
M.Likitha

## Description
This program demonstrates using a void pointer to pass
an integer array to memset().

memset() is used to set all bytes of the integer array
to zero.

## Concepts Used
- Void pointer
- Integer array
- memset()
- Memory initialization
- sizeof operator

## How to Run

gcc void_pointer_integer_array.c -o void_pointer_integer_array

./void_pointer_integer_array

## Sample Output

Before memset: 1 2 3 4 5
After memset: 0 0 0 0 0
